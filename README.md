# Bioimage Analysis Notebooks: From Pixels to U-Net

A set of **educational Jupyter notebooks** that teach bioimage analysis, from what a pixel is to training a small deep-learning model. They are written for undergraduates, graduate students and early-stage researchers in biology, medicine and computer science.

Everything is built around one real research question: **detecting extrachromosomal DNA (ecDNA) in FISH microscopy images of cancer cells.** Classical image processing and modern AI are taught side by side, on the same data, with honest evaluation.

## 🚀 Quick start

**Easiest:** click an *Open in Colab* badge above. The notebook downloads the example data itself.

**Locally, with conda/mamba:**
```bash
git clone https://github.com/PooryaBehnamie/bioimage-analysis-notebooks.git
cd bioimage-analysis-notebooks
conda env create -f environment.yml
conda activate bioimage-env
jupyter lab
```

**Locally, with pip:**
```bash
python -m venv bioimage-env
source bioimage-env/bin/activate      # Windows: bioimage-env\Scripts\activate
pip install -r requirements.txt
jupyter lab
```

Tested with Python 3.11, on both the minimum package versions in `requirements.txt` and the latest releases (September 2026). Every notebook runs top to bottom without errors, and results are reproducible (fixed random seeds).

## 🔬 Example data

The `data/` folder contains one metaphase FISH image of NCI-H2170 lung cancer cells (DAPI in gray, ERBB2 probe in red, MYC probe in green), its DAPI channel, and MIA-predicted ecDNA spots. The images come from the Brunk Lab's [ecEnhance](https://github.com/Brunk-Lab/ecEnhance) repository (MIT License). See [`data/README.md`](data/README.md) for details.
